# OpenQR Identity

![OpenQR logo](assets/openqr-logo.svg){ .openqr-mark }

The three scan corners represent acquisition. The central record and outward
arrow represent resolution beyond the printed endpoint. The mark is intentionally
not a valid QR code and must not replace a functional barcode.

Bold geometry and a contrasting signal accent connect it to the Mainstay and
Clear branch of the product family. Teal gives OpenQR a distinct role alongside
OpenETR's evidence model and Stroma's connectivity layer.

| Colour | Value |
| --- | --- |
| Scan teal | `#147d83` |
| Record ink | `#163f4b` |
| Resolution coral | `#e16f51` |

Use the [SVG master](assets/openqr-logo.svg) on a light background with clear
space around the mark. The app's master is `app/static/openqr-logo.svg`; the
documentation copy must remain identical.
